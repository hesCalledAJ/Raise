# Raise ⏰

**Raise** is a **Material You** alarm app for Android, being built with **Kotlin** and **Jetpack Compose**.


This project is the successor to my previous alarm app, [Wakee](https://github.com/alijafari-gd/Wakee), which has 20K+ installs on Iran's app market.  

## Goal
A Simple yet effective way to wake up for both heavy sleepers or normal users ; using Challenges like scanning a QR code or walking a few steps

## Installation
Download the latest **Release** from GitHub and install on your device.  

## Tech Stack
- **Language:** Kotlin  
- **Architecture:** MVVM + Clean Architecture  
- **Dependency Injection:** Hilt  
- **Database:** Room
